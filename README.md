# 霧晴れの開拓譚（StudyGame）

行動経済学・心理学の知見を取り入れた、ブラウザだけで完結する学習Webゲームです。
Vanilla JavaScript / HTML / CSS のみで実装されており、外部フレームワーク・サーバーは使用していません。

- `index.html` … エントリーポイント
- `css/` … スタイル（機能ごとにファイルを分割）
- `js/` … モジュール分割されたロジック（役割ごとにファイルを分割）
- `assets/` … 画像・動画・音声などの静的アセット
- `HANDOFF.md` … セッションをまたいだ引き継ぎ用の継続ドキュメント（毎セッション追記）

## 使い方

1. `index.html` をブラウザで開く（ローカルサーバー経由推奨。`file://` だと一部ブラウザでIndexedDB等が制限される場合があります）。
2. 初回はバックアップJSONの読み込み、またはそのまま「この端末の保存データで続ける」で開始できます。
3. 1日1回ログインすれば、日付が変わるまで再ログインは不要です。

## 音声（BGM）について

`assets/audio/` フォルダに以下のファイルを置くと、画面ごとにBGMが流れます（無くても動作します）。

```
assets/audio/home.mp3      … ホーム画面
assets/audio/explore.mp3   … 探索画面
assets/audio/settings.mp3  … 設定画面
assets/audio/stage.mp3     … ステージ画面（地図）＋ 問題を解いている間
```

## 追加判断

マスター仕様書80〜81章「現状のサイトでより行動経済学と心理学を考慮した学習を行うために追加で必要だと考えられる機能」への対応として、以下の機能をClaudeの判断で追加しました。仕様に明示されていない部分のため、ここに明記します。

### 「今日の目標」機能（コミットメント・デバイス／実行意図）

**追加した機能**

ホーム画面に「今日の目標」ボックスを追加しました。

- その日まだ目標を決めていない場合、「1問」「3問」「5問」のいずれかをワンタップで選ぶだけの簡単な宣言UIを表示します。
- 選んだ後は、新規学習・復習を問わずクエストを1つ完了するたびに進捗（`◯ / 目標`）が進みます。
- 目標に達すると「達成しました！」という肯定的な表示に変わります。
- 日付が変わると自動的に未設定へ戻り、また新しく決め直します。

**採用した行動経済学・心理学的根拠**

- **コミットメント・デバイス**：小さくても「自分で決めて宣言する」行為自体が、後の行動を後押しする（行動経済学における実行のハードルを下げる代表的な手法）。
- **実行意図（if-thenプランニング）の簡易版**：「今日は何問やるか」を先に決めておくことで、迷いなく行動に移しやすくする。
- **ゴール勾配効果との併用**：「あと◯クエスト」という表示は、既存の設計図・ステージ進捗の表示パターンと統一し、認知負荷を増やさないようにした。
- **損失回避への配慮**：目標未達成でも、コンパスや設計図・建築物・キャラクター等、何かを失うことは一切ない設計にした。目標はあくまで前向きな目安であり、罰にはしていない（仕様81章「休んだユーザーを強く罰しない」「報酬ゼロで失敗を強調しない」との整合を優先した）。

**実装箇所**

- `js/gameState.js`：`state.dailyGoal { date, target, completed }` を追加。`setDailyGoal` / `getDailyGoal` / `recordQuestCompletionForDailyGoal` を実装。
- `js/resultSystem.js`（新規学習クエスト成功時）、`js/reviewSystem.js`の`completeReview` / `completeStarReview`（復習クエスト完了時）から、クエスト完了のたびに`recordQuestCompletionForDailyGoal()`を呼び出す。
- `js/router.js`の`renderHomeScreen`に`renderDailyGoalBox()`を追加。

**Saito様にご確認いただきたい点**

- 目標の選択肢を「1 / 3 / 5問」の3択で固定しました。人数やペースに応じて選択肢を増やす／数値を変えることは容易ですが、まずは選択肢を絞って認知負荷を下げる方針（仕様70章）を優先しました。
- 「1クエスト」の単位は、新規学習のLv1〜3各1回、復習の各形式1回、☆フォルダ復習1回をすべて等しく「1」としてカウントしています。難易度差の重み付けは行っていません。

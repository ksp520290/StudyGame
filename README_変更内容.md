# 変更内容（追加要望② 対応）

ベースの `ver_1_0` に対して、「追加要望②」で挙げられた項目を実装しました。

## 実装した内容

1. **履歴（バージョン管理メモ）の復元機能**
   - 「履歴に追加」時に、その時点の状態（台本・Cue・配役・独自Effect・ステージ設定など）をスナップショットとして保存。
   - 各履歴の右側に「復元」ボタンを追加し、確認ダイアログの後にその時点の状態へ復元できます。

2. **ステージ画面のフェード秒数入力を削除**
   - 右（下）のステージ画面から数値入力の「フェード秒数」欄を削除。
   - 代わりにステージ画面に「フェードなし → フェードイン → フェードアウト」と切り替わるボタンを設置。
   - フェードの**時間（秒）**自体は、ログイン後の「⚙ 設定」→「フェード秒数」ボタンから変更する仕様に変更しました。

3. **「chs」表記をすべて「Effect」に変更**
   - Cue一覧のテーブル見出し、CSV出力見出し、印刷レイアウトを含め、「chs」という表記をすべて「Effect」に統一しました。

4. **ステージ部分で動画表示に対応**
   - これまで画像のみだったステージ表示部分に `<video>` 要素を追加。
   - 「ステージ動画を直接指定」ボタンから動画ファイルを選ぶと、そのままステージにループ再生されます（このアップロードはブラウザのセッション内のみ有効です）。
   - 背景色ありモードでは、後述のフォルダ構成に応じて画像(img)/動画(mov)が自動選択されます。

5. **QRコード機能の削除／ヘッダー配置の変更**
   - QRコード生成ボタン・モーダル・関連ライブラリ読み込みをすべて削除しました。
   - ログイン後、「設定」という言葉でまとめず、ヘッダーに **JSON出力／JSON読込／印刷／初期設定** を横並びのボタンとして配置しました。
   - 残りの操作（CSV出力・練習/本番モード切替・フェード秒数・管理者画面・ログアウト）は「⚙ 設定」から表示されます。

## 初期設定モーダルの変更

- ストロボ（クルクル/チカチカ/なし）の動画選択部分は削除しました。
- 設定2は「2色以上の高速切り替え（Effect）」に名称変更し、選択肢は **あり／なし** の2択。
- 「あり」を選んだ場合のみ「Effectの種類選択」（**既存Effect／独自Effect**）が表示されます。

## ステージ画面（背景色ありの場合）の演出コントロール

色スウォッチ（8色・色相順：赤→オレンジ→黄色→緑→青緑→青→ピンク→白）を中央に配置し、左に「ストロボ」ボタン、右に「フェード」切替ボタンを配置しました。

- **高速切り替え「なし」**：ストロボは単純なON/OFFボタン。
- **高速切り替え「既存Effect」**：ストロボボタンは「ストロボ静止 → ストロボチカチカ → ストロボクルクル → ストロボ✖️」の4状態を巡回。右横に「Effect」ボタン（ON/OFFのハイライト表示）を追加。
- **高速切り替え「独自Effect」**：ストロボボタンは「ストロボ✖️ → ストロボ静止 → ストロボチカチカ → ストロボクルクル」の順で巡回。「Effect」ボタンは「Effectなし → 既存Effect → 独自Effect」の順で巡回します。
  - 「独自Effect」が選択されると、色の行の下に **No. / ステップ / 秒数 / 保存** の入力行が表示されます。
    - No. はデフォルトで1、既存の番号と重複する場合は自動的に空いている番号を提案します。
    - ステップはデフォルト1で、保存するたびに+1されます。
    - 秒数はデフォルト0.1、0.1刻み（PCでは上下キーでの増減に対応、標準の number input の仕様を利用）。
  - 保存すると「独自Effect」タブの一覧表（No./ステップ/秒数/背景色（日本語）/ストロボ）に追加されます。

すべての色ボタン・ストロボ・Effect・フェードの状態は、選択されている舞台（暗転/全照/半照）とストロボ状態に応じて、次のフォルダ構成の画像・動画を自動的に参照します（ファイルが無い場合は色フィルターのみで表示されます）。

```
img/ または mov/
  └ 暗転 | 全照 | 半照
      └ ストロボ✖ | ストロボ静止 | ストロボ独立 | ストロボくるくる
          └ 赤.png / オレンジ.png / 黄色.png / 青.png / 白.png / ピンク.png / 緑.png / 青緑.png
```

※ アップロードいただいた `ver_1_0.zip` 内のフォルダ名が文字化けしていたため（例: `#U5168#U7167`）、正しい日本語フォルダ名（`全照` 等）に修正した上でパッケージしています。`img/anten.jpg.png` という二重拡張子のファイルも `img/anten.jpg` に修正しました。

管理者画面からも、種別（img/mov）・舞台・ストロボ・色を選んでファイルをアップロードすると、このフォルダ構成に沿ったパスとして保存され、即座に反映されます。

## Cue画面の記録内容（chs→Effect対応後の仕様）

| 項目 | 内容 |
|---|---|
| 秒数 | Cue記録ボタンを押した時点の動画／音源の秒数 |
| セリフ | 記録時に選択されていたテキスト範囲（未選択時は空欄） |
| 音源 | 音源を切り替えるたびに①②③…と表示（初回読み込み時に①、以降切替のたびに増加。※簡略化のため、切替前に遡って番号を付け直す処理は行っていません） |
| 舞台 | 暗転／全照／半照 |
| 背景 | 選択中の色を日本語で表示 |
| Effect | 高速切り替えが「独自Effect」で、かつEffectボタンが有効な状態のときのみ「◯」 |
| ストロボ | ストロボ静止=「◯」、ストロボチカチカ=「チカチカ」、ストロボクルクル=「Effect1」、ストロボ✖️=「なし」 |

「独自Effect」タブにも、他タブと同様にCue記録ボタンを設置しています。

## 簡略化した点（ご了承ください）

- Googleドキュメント自動同期は、CORSの制約上、ブラウザから直接取得できない場合があります（ドキュメントを「ウェブに公開」設定にする必要があります）。
- フェードイン／フェードアウトは、CSSの `opacity` トランジションによる簡易実装です。フェードアウト時は「現在の映像が指定秒数かけて透明になった後に次の映像へ切り替わる」動作にしています。
- 独自Effectの「秒数」欄は、保存後にリセットしていません（前回入力値が残ります）。No.とステップのみ自動更新されます。

以上、既存のログイン機能・複数話者マッチング・スクリプト内音源プレーヤー・追従ツールバー・ダークモードでの台本文字色などは、`ver_1_0` の実装をそのまま踏襲しています。

# 変更内容（ver_1_1(ver.1.3) → 今回の追加要望13項目 対応）

1. **配置アイテムの削除機能**：ステージ上の配置アイテムをクリック（選択）すると、アイテム右上に「✖」ボタンが表示され、押すとそのアイテムを削除できるようにしました。
2. **Googleログインを「設定」画面へ移動＋認証方式の変更**：初期設定モーダルにあった「Googleアカウントにログイン」を廃止し、ログイン後の「⚙ 設定」メニューに「Googleログイン」ボタンを新設しました。学校でGoogle Cloud Consoleが利用できない制約に対応するため、OAuthクライアントIDによる自動認可の代わりに、**Google OAuth 2.0 Playground**等でご自身が事前に取得したアクセストークンをテキスト欄に貼り付けて「この情報でログイン」を押す方式に変更しています。貼り付けると同じ画面内でログイン済み状態（ステータス表示＋ログアウトボタン）に切り替わります。取得したトークンはセッション内のみで保持し、保存はされません。
3. **配役サイドバー開時の重なり解消（横画面のみ）**：横画面（幅900px以上・ランドスケープ）で「配役」パネルを開くと、台本／動画／Cueタブ画面とステージ表示画面全体を配役パネルの幅（340px）分だけ圧縮表示し、重なりを解消しました。縦画面では画面が細くなりすぎるため、この圧縮は行わず、これまで通りの表示のままです。

5. **自動マイク割り当てをワイヤレス内で循環**：人物追加時の自動マイク割り当てを「ワイヤレス1→2→3→4→1…」とワイヤレスの4本だけで循環するように変更しました。手動でのマイクボタン切り替えは従来通り、自動設定されたマイクから始まり「ワイヤレス4の次は有線1」「有線4の次はワイヤレス1」に戻る全8種の巡回のままです。
6. **役者名入力欄の縮小**：配役パネルの「役者名」入力欄の幅を、これまでの約70%に縮小しました。登場人物名の入力欄・保存ボタンのサイズは変更していません。
7. **読み上げ音声切り替えボタンの追加**：各配役行の「変更」ボタンの右横に「voice」ボタンを追加しました。押すたびに「男1（低）→男2（中）→男3（高）→女1（低）→女2（中）→女3（高）」の順で読み上げ音声を切り替えられます。
8. **音声生成中の表示**：読み上げボタンを押した瞬間から実際に音声再生が始まるまでの間、ボタン表示を「音声生成中」にし、再生が始まると「⏹ 停止」に切り替わるようにしました。
9. **読み上げ中のCue記録機能を廃止し、選択範囲記録に統一**：読み上げ中に読み上げられている行を自動的にCueの「セリフ」欄へ記録する仕組みを廃止しました。Cue記録ボタンは、読み上げ中かどうかに関わらず、常にそのとき選択（ドラッグ選択）されている文字範囲のみをセリフ欄に記録します。
10. **favicon（icon.ico）の透明化**：アップロードいただいた `icon.ico` は、ファイル形式上はRGBA（透過対応）でしたが、実際には全サイズ・全ピクセルの透過度（アルファ値）が255（完全不透明）になっており、円形イラストの外側が白／薄灰色で塗りつぶされたまま保存されていました（透過処理自体が反映されていない状態でした）。今回、円形イラストの外側部分をアルファ値0（透明）にした上で、16×16〜256×256の全サイズを再生成し直しましたので、ブラウザのファビコンとして表示した際も背景が透過されるようになりました。
11. **読み上げ内容を「話者自動マッチングでマッチしたセリフ部分のみ」に整理**：読み上げ処理を、行のテキストから話者名部分を正規表現で除去する簡易処理から、ルビ解決後のテキストに対して話者名＋区切り文字（「：」「:」または全角/半角スペース2文字以上）を取り除いた上で読み上げる処理に整理しました。あわせて、話者自動マッチングで判定された話者（`data-speaker`）に対応する配役の「voice」設定を読み上げ時に自動的に適用します。
12. **選択範囲のみの読み上げ機能**：台本エディタ内でテキストを範囲選択してから「読み上げ」を押すと、これまでは選択箇所から最後まで読み上げていましたが、今回から選択範囲に含まれる行だけを読み上げ、選択範囲外へは読み進めないようにしました（未選択の場合は従来通り全体を読み上げます）。
13. **ルビの二重読み上げを解消**：ルビ（`<ruby><rt>`）を振った文字について、読み上げ時に「漢字部分」と「ふりがな部分」の両方が読み上げられて2回読みになっていた問題を修正しました。読み上げ時はルビの`<rt>`（ふりがな）のみを読み上げ対象とし、元の漢字表記は読み上げないようにしています。

## 今回の簡略化・技術的な制約に関する補足

- **Googleログイン（要望②）**：ブラウザ単体の静的サイトであるため、OAuthの自動認可フロー自体を完全に代替することはできません。今回はご自身で外部ツール（OAuth 2.0 Playground等）から取得したアクセストークンを貼り付ける方式としています。トークインには有効期限があるため、期限切れの場合は再度取得・貼り付けが必要です。
- **読み上げ音声の「男/女・低音/中音/高音」（要望⑦）**：ブラウザの音声合成（Web Speech API）は、OS・ブラウザにインストールされている音声にしか対応していないため、常に男女6段階の声質が個別に用意されているとは限りません。今回は、日本語音声の中から名前に「male/female」等を含むものを優先的に選択しつつ、`pitch`（声の高さ）と`rate`（speaking速度）をボタンごとに変えることで、低音〜高音の聞こえ方の違いを表現する簡易的な実装にしています。使用環境によって聞こえ方の差が小さい場合があります。
- **「音声生成中」表示（要望⑧）**：Web Speech APIには明確な「生成中」フェーズの通知がないため、読み上げボタンを押してから実際に音声再生が開始されるまでの間を「音声生成中」として表示しています。
- **favicon修正（要望⑩）**：デザインファイル（PSD等の元データ）はお預かりしていないため、円形イラストの外形に沿って自動的に透過処理を行いました。イラストの縁ぎりぎりまで絵柄が入っているため、境界線付近の見え方に若干の違いが出る可能性があります。
